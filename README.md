# Portfolia — Full Vercel Deploy (Frontend + API)

Everything runs on Vercel for free. No Render needed.

## Environment Variables (Vercel)

| Name | Value |
|------|--------|
| `FIREBASE_WEB_API_KEY` | Firebase Web API Key |
| `FIREBASE_SERVICE_ACCOUNT` | Full JSON from serviceAccountKey.json (paste as one line) |

Do NOT add ADMIN_EMAIL or ADMIN_PASSWORD.
Do NOT add VITE_API_URL (API is on the same domain).

## Deploy

1. Push this folder to GitHub (files at repo root)
2. Import in Vercel
3. Add the 2 environment variables above
4. Deploy
